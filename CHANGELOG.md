## [4.1.0] - 2026-11-21

### Security
- **Chained-Command & Flag-Order Pre-Flight Guard Hardening (`core/guard.ts`, `core/redact.ts`)**: Added quote-aware O(n) shell segment splitting (`splitShellSegments`), multiline-safe quote masking, and argument tokenization (`splitShellArgs`), closing chained-command and flag-order bypasses across `destructive-rm-root` (`rm -rf ./dist /`, `rm -rf -- /`, `rm -rf -v /`, `rm --no-preserve-root -rf /`, `rm -rf ./.git`), `sql-destructive-ddl` (`echo ok && psql -c "DROP TABLE ..."`), `git-reset-hard` (requires `git stash` in an earlier segment; preserves `-C <dir>`), `git-clean-force` (`git clean -n && git clean -fd`), `git-no-verify-bypass` (bundled `-nm`/`-anm` rewritten per-segment without touching `head -n 5` or `git push -n`), `git-force-push` (`--force-with-lease -f`), and `lockfile-drift` (`npm install -D vitest` → `pnpm add -D vitest`). Raised secret scan window to 64 KiB, fixed `AGENTS.md #17` false positive so `const apiKey = process.env.OPENAI_API_KEY;` is never blocked by `hardcoded-secret-literal`, and widened `Cookie`/`Set-Cookie` redaction across semicolon attributes.
- **LLM SSRF & Redirect Defense (`core/llm.ts`, `core/prompts.ts`, `core/distiller.ts`)**: Hardened `assertSafeEndpoint()` against trailing DNS dots (`localhost.`, `metadata.google.internal.`), cloud metadata aliases (`metadata.goog`, `instance-data`), full IPv6 `fe80::/10`, `fc00::/7`, `ff00::/8`, `100::/64`, `64:ff9b::/96`, hex-normalized `::ffff:7f00:1`, and legacy IPv4-compatible `::127.0.0.1`; disabled automatic redirects (`redirect: 'manual'`, throwing on HTTP `3xx`); made retry backoff & pacing abortable via `AbortSignal`; preserved Azure-style query strings (`?api-version=...`); retried transient `408`/`503`/`504`; escaped prompt XML tags (`</failed_call>`, `</successful_call>`) in `buildDistillInput`/`buildCritiqueInput` and redacted critique drafts; applied pre-distill skip gates (`TRANSIENT`, `PERMISSION_DENIED`, retired-meta) before calling `chat()`.
- **Local Dashboard DNS-Rebinding & Framing Protection (`core/ui/server.ts`, `dsh/src/ui-route.ts`)**: Enforced strict loopback `Host` validation (`403 forbidden host`), appended `frame-ancestors 'none'` to CSP, aligned `/api/guard` body limit to 64 KiB, returned clean HTTP `413` on oversized bodies, made `handle.close()` idempotent, and closed the store on bind errors.
- **Delimiter, Privacy & Symlink Hardening (`core/hygiene.ts`, `core/store/stuck.ts`, `dsh/src/index.ts`, `core/skill-ingest.ts`)**: Eliminated OS username leaks in 2-segment home paths (`C:\Users\alice\.env` → `<path>/.env`, `/Users/alice/Desktop` → `~/<path>/Desktop`) and guarded `abstractMachinePaths` against drive/filesystem root inputs (`/` or `D:\`); sanitized angle brackets & credentials in `stuckHypothesisText()` and DSH `thrash` notes; placed DSH advisories inside `<immune_memory>...</immune_memory>`; added `realpathSync` cycle detection + depth cap (12) and 512 KiB file cap in `core/skill-ingest.ts`.

- **Connectors, Git Hooks, Disk Ingest, Audit, UI & Doctor (`core/connect.ts`, `core/git-hook.ts`, `core/disk-ingest.ts`, `core/audit/logs.ts`, `core/audit/magpie.ts`, `dsh-immune-system/client/client.js`, `core/ui/client-script.ts`, `zcode/src/doctor.ts`, `zcode/src/commands/*`)**: Made `vendorDist()` atomic via sibling staging, detected Cursor sidecar-only `.cursor/mcp.json` in `connectStatus()`, and persisted stale duplicate hook cleanup; honored Git `core.hooksPath` and inserted pre-commit blocks before trailing `exit`/`exec`; discovered `depth === 0` project roots in `ingestDiskCorpus()` and filtered rubric before per-project slicing; eliminated Magpie `usage.jsonl` + `routing/` double-counting; added request sequence cancellation & cleanup in `client.js` and fixed `/` hotkey inside Guard/Explain inputs; added `schema`, `pre-flight guard`, `receipt chain` (fails red if tampered), and `vaccine lockfile` rows to `immune doctor` (using `readLlmConfig()` for Magpie/Ollama); enforced total drain deadline and strict CLI flag/port validation.
