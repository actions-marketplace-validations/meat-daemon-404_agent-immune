# Changelog

All notable changes to **agent-immune** (`dsh-immune-system`) are documented in this file.

## [4.0.0] - 2026-11-21

### Added
- **Unified Live Pre-Flight Guard & Persistent Audit Ledger (`core/guard.ts`, `core/runtime.ts`, `core/store/guard-events.ts`, `dsh/src/index.ts`)**: Replaced the legacy 5-rule live hook guard (`core/guards.ts`) with the full 12-policy Pre-Flight Blast-Radius Guard across every live host adapter (Claude Code, Codex, Cursor, Antigravity, Gemini CLI, ZCode, and DSH `tools/pre-execute`). Adds live workspace lockfile-drift interception (`pnpm`/`yarn`/`bun`/`uv`), live secret-literal interception with redacted banners/logs (AGENTS #10), quote-aware SQL DDL protection (blocking `psql -c "DROP TABLE"` while allowing `git commit -m "fix DROP TABLE"` and `grep "DROP TABLE"`), new `raw-disk-dd` and `pipe-to-shell` policies, native DSH interactive `IMMUNE_GUARD=ask` confirmation mode, and persistent `guard_events` SQLite auditing (`immune guard --log`, `immune_guard_log` MCP #27, `GET /api/guard-events`). Learned DB antibodies never auto-block on the live path (AGENTS #8).
- **MCP v4 Full Protocol — 27 Tools, 5 Live Resources & 3 Workflow Prompts (`zcode/src/mcp-server.ts`)**: Advertises `tools`, `resources`, and `prompts` capabilities on `initialize`; adds `immune_guard_log` (#27), 5 read-only live URIs (`immune://library/active`, `immune://stats/summary`, `immune://workspace/dna`, `immune://guard/events`, `immune://insights/report`), and 3 reusable workflow prompts (`immune_review_pitfalls`, `immune_triage_failure`, `immune_rewrite_echoes`).
- **Unified v4 Command-Center Dashboard & DSH Shadow-DOM Parity (`core/ui/query.ts`, `core/ui/template.ts`, `core/ui/client-script.ts`, `dsh-immune-system/client/client.js`)**: Consolidated `/api/insights`, `/api/guard`, `/api/guard-events`, and `/api/federate` into `core/ui/query.ts` with real receipt/guard telemetry (removing synthetic multipliers); shipped interactive **Guard Simulator + Live Audit Log** and **Insights + 5-Domain Radar + Autopsy + Workspace DNA + Swarm Federation** tabs in BOTH the 100%-offline standalone HTML dashboard and the DSH Shadow-DOM settings tab (plus closed the missing **Explain** tab gap in `client.js`).
- **3 High-Impact Builtin Seed Packs — 12 Packs / 72 Rules (`core/packs.ts`, `core/prewarm.ts`, `core/retrieval.ts`, `scripts/bench-seed-recall.mjs`)**: Added `sql-migrations`, `nextjs-react`, and `windows-shell` (18 new hand-authored rules), all CI-gated at **R@1 100% (72/72), R@3 100% (72/72), FP 0% (0/9)**.
- **OpenCode & Kiro Connectors + Verified `.immune/vaccine.lock.json` Auto-Hydration (`core/connect.ts`, `core/vaccine.ts`, `core/runtime.ts`, `dsh/src/index.ts`)**: Added native `opencode` (`mcp` local array format) and `kiro` (`mcpServers`) connectors (13 direct `connect` hosts + DSH + ZCode); wired automatic SHA-256-verified `.immune/vaccine.lock.json` hydration, cold-start `prewarm`, and two-way `.immune/rules.jsonl` team sync symmetrically across both ZCode hooks and DSH.

### Performance & Fixed
- **Sub-Millisecond Hook Hot Path (`core/store/open.ts`, `core/store/episodes.ts`, `core/store/rerank.ts`, `core/store/index.ts`)**: Gated schema DDL & 25 `PRAGMA table_info` checks behind `PRAGMA user_version = 4`; short-circuited `claimFailure()` with a single `SELECT 1` read when `pending_failures` is empty (eliminating 9 WAL `DELETE` writes on clean tool calls); precomputed `prepareLexicalQuery()` once outside `rerank()`'s candidate loop; stamped `antibodies.promoted_at` for single-shot `GlobalStore` promotion. Full test suite wall time dropped ~30% (`9.15 s -> 6.54 s`, `p50` A/B recall `0.005 ms`).
- **Closed-Loop Real `'held'` Receipts & Concurrency-Safe SHA-256 Chain (`core/receipts.ts`, `core/runtime.ts`)**: Serialized `recordDeliveryReceipt()` inside `BEGIN IMMEDIATE` to eliminate parallel-hook hash chain forks, and added turn-end `settleTurn()` emitting verified `'held'` receipts so `receiptSummary.estimatedTokensSaved` and `modelImmunity.tokensEstSaved` report real non-zero savings.
- **Core Correctness Fixes (`core/tools.ts`, `core/store/schema.ts`, `core/store/antibodies.ts`, `core/env-fingerprint.ts`, `core/git-hook.ts`, `zcode/src/hooks/user-prompt-submit.ts`, `dsh/src/dsh-adapter.ts`)**: Centralized cross-host tool normalization in `core/tools.ts`; upgraded `pending_failures` PK to `(session_id, tool_name, target_signature)` with safe v3→v4 migration so concurrent tool failures never clobber each other or sibling repair buffers; eliminated mixed EN+ZH CJK bigram starvation in `findMatches()`; filtered `insertAntibody()` exact-match to `status = 'active'`; preserved `triage_bucket = 'ignored_by_agent'`; added lockfile mtime/size cache invalidation to `currentFingerprint()`; fixed Git worktree `commondir` hook resolution; stopped Cursor `beforeSubmitPrompt` from inflating `hit_count` / writing phantom receipts; made DSH `makeLogger()` null-safe and closed `store` on startup abort.
