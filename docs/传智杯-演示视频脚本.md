## 逐字讲解词

### 【00:00 – 00:45】痛点引入与项目定位
> “各位评审老师好，我是来自**云南大学光电信息科学与工程专业**的**孙梓航**。今天展示我的个人赛参赛作品：**`agent-immune`（包名 `dsh-immune-system@2.0.0`）——面向多宿主编程智能体的自进化因果免疫与安全控制平面**。
> 平时在使用 Claude Code、Codex、DSH 或 ZCode 等 Coding Agent 写代码时，我们常遇到两个痛点：第一，模型总会在同一个环境坑、报错路径上重复踩坑浪费大量 Token；第二，简单记录历史很快就会被 `Write: 某绝对路径` 或临时 `grep`/`pwsh` 探测命令污染，越注入越误导模型。
> 而 `agent-immune` 在**零第三方运行时依赖**的前提下，把『失败后被修好』的因果链条蒸馏成带触发词、忌、宜的结构化抗体，用五维质量评分门禁把垃圾挡在库外，在模型即将再犯错之前精准唤醒记忆。”

### 【00:45 – 01:45】30 秒零依赖实机演示
> “现在看终端实际运行：`package.json` 里的 `dependencies` 完全为空，只用 Node.js 24 原生内置的 `node:sqlite` 和 `node:zlib`。
> 执行 `node dsh-immune-system/dist/zcode/src/cli.js demo`，它在纯内存里完整跑通了一轮从命令失败、修复配对、规则蒸馏、双语改写检索到生成 `<immune_memory>` 注入块的闭环。通过 `immune connect`，这一套 `core/` 引擎还能自动探测并接入 ZCode、DSH、Claude Code、Codex CLI 与 Google Antigravity 五大生态宿主。”

### 【01:45 – 03:15】v2.0 核心技术栈与 AI 深度优化
> “为了彻底解决早期版本『规则污染与误淘汰』的问题，我在 v2.0 做了四项关键技术重构：
> 第一，**五维 Rubric 质量评分与工作区作用域锁**（指向 `core/rubric.ts` 与 `core/hygiene.ts`）：每条规则按特异性、可操作性、可迁移性、证据强度和防泄漏五维度打分，并自动剥离机器本地路径、分配工程指纹。只有真正可跨仓复用的经验才能进入全局共享。
> 第二，**四级推理与 Agentic 自我反思批判**（指向 `core/prompts.ts` 与 `core/distiller.ts`）：支持云端兼容接口、本机 Magpie 网关 / Ollama，甚至通过 MCP 借用宿主大模型零 API 费用改写历史规则。当大模型首轮输出 Rubric 不足 68 分或被门禁隔离时，系统会把具体失分诊断反馈给模型触发 1-shot 自批判重修，大幅抬升处方可用率。
> 第三，**Red-3 五桶分诊与链式 SHA-256 回执**（指向 `core/triage.ts` 与 `core/receipts.ts`）：注入后依然报错时，系统会先区分到底是网络波动、跨项目串台、还是模型连续忽视；针对模型反复无视的通用高价值规则，动态前置 `[CRITICAL · ignored N×]` 强警示而不是错误淘汰它，所有投递结果均带防篡改链式摘要。
> 第四，**双语概念图检索与长 Diff 尾窗修复**（指向 `core/retrieval.ts` 与 `core/relevance.ts`）：融合 FTS5 三元组与 2 字符中文 LIKE 兜底、19 组中英开发概念扩展及重排器，让 42 题内置种子集首位召回率 **R@1 从 69% 跃升至 95%**。”

### 【03:15 – 04:30】真实本地大数据集消融与 Magpie 协同实战
> “接下来展示在**真实生产库与近 3 万次本地真实调用日志**上的实测效果（终端执行 `cli.js models` 与 `node scripts/bench-ablation.mjs`）。
> 首先看 `cli.js models`：工具以严格不碰凭证的只读方式解析了本机 **Magpie 多模型网关 11,165 次路由请求、76.7% 缓存命中与 70 个模型 ID**，并与本地规则投放回执联合统计单模型存活率与高危忽略升级列表。
> 再看实时跑出的消融对比输出：
> 在 ZCode 生产库 57 条规则上，活跃垃圾规则比例从 **70.4% 直接清零到 0.0%**，平均质量分从 **68.9 提升到 94.4 分**；在 DSH 实库 33 条规则上，活跃垃圾比例从 **100.0% 降至 0.0%**，跨仓误泄露全部清零。
> 随后脚本用 3 秒钟扫描整块 `D:\` 盘 **184 个工程与 Skill**，自动沉淀 **937 条结构化规则**；再对 ZCode、Codex 和 Antigravity 累计 **28,961 次真实工具调用**做严格按时间向前、不偷看未来的**因果反事实回放**：仅靠从零流式自学习（Cold-Start），结合误差尾窗与连字符拆分改造，就能在同类错误再次发生前提前拦截 **88.5%**；预热内置包与全盘规则先验后（Warm-Start），重复踩坑提前拦截率高达 **96.9%（126 / 130）**、全故障事件覆盖率达 **94.3%**。”

### 【04:30 – 05:30】离线 Web 看板与 245 项全绿自动化门禁
> “系统同时提供了完全离线的 Web 控制台（演示 `cli.js ui` 打开浏览器页面）和面向 DSH 的 Shadow-DOM 设置页签。页面上直观展示了活跃与隔离规则数、平均 Rubric、进化曲线、单模型存活百分比、Red-3 分诊气泡与 SHA-256 校验态，且提供一键「治污 / hygiene」与合规检查拦截机制。
> 最后展示自动化质量验证门禁（运行 `npm test` 与 `scripts/bench-seed-recall.mjs`）：全部 **245 项单元测试 0 失败全绿通过**，对 21,034 次历史调用的故障分类一致率达 **97.81%、0 漏报**，单次本地索引检索中位延迟仅 **0.58 毫秒**，工具热路径仅 **1.697 毫秒**。”
